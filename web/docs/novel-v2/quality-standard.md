# 高质量长篇网文质量标准（novel-v2 审核锚点）

> 本文档是 novel-v2 流程审核的**文学质量锚点**，不是工程可靠性锚点。
> 工程可靠性见 `outputs/novel-v2-framework-audit-2026-07-29.html`（五审硬门禁/payoff provenance/记忆指纹等）。
> 本标准从范例小说研究推导，目的是让审核判断对照**固定可审计的尺**，而非临时口味。
>
- **来源**：烽火戏诸侯《剑来》（1332 万字）、《雪中悍刀行》（461 万字，豆瓣 8.7）；超级大坦克科比《我在风花雪月里等你》（194 万字）。
- **适用范围**：novel-v2 全流程（foundation → arc → blueprint → preflight → draft → reflection → five-reviewer → revision → commit → fact → memory → learning/promote）的每一步产物、提示词、审核逻辑与审核提示词。
- **非目标**：不替代工程可靠性审核；不针对单一题材/角色名/段落做 case-specific 规则；不要求每章机械出现某维度。
- **使用方式**：每一步审核对照本标准的维度与判据，缺口按根因层（shared contract / schema / prompt / skill / validation hook）分类，按 AGENTS.md 修复。

## 0. 范例小说研究结论（标准推导依据）

### 0.1 《剑来》— 文明史诗 / 修心叙事
- **文笔**：文白相济、诗化凝练；叙述以简驭繁，善用留白与顿挫；对话精准呈现人物身份与心境（齐静春温润含蓄、崔东山诡谲跳脱、朱敛市井机锋各具声口）；化用诗词典故不着痕迹。
- **叙事**："草蛇灰线，伏脉千里"——多线并置、时空折叠，关键伏笔跨越数百章埋设（"槐叶""碗水""四脚蛇"等意象反复出现、层层赋义），形成环环相扣的叙事闭环与重读价值。
- **群像**：齐静春以身殉道、崔瀺智谋复杂、阿良潇洒不羁、宁姚独立自强——每个配角都有完整弧光与自身执念，无绝对善恶。
- **慢热反爽**：拒绝"三年筑基五年金丹"速成神话，代之以"十年磨一剑，百年养一城"的耐心沉淀；主角不杀伐果断，隐忍善良倔强。
- **思想**：儒释道融合，"讲道理"而非"讲故事"；意象承载哲思（本命瓷隐喻命运枷锁，剑气长城探讨文明冲突）。
- **缺点（反面教材）**：超 1200 万字导致中后期节奏拖沓、支线冗杂泛滥；部分段落过度沉溺哲思、行文晦涩；重复说教段落偏多。

### 0.2 《雪中悍刀行》— 江湖庙堂双轨 / 群像封神
- **群像（核心优势）**：李淳罡"天不生我李淳罡，剑道万古如长夜"、温华自断手足换兄弟平安、轩辕敬城隐忍半生一步入陆地神仙——"随便拎一个配角出来，人物弧光完整到能单独开一本支线"。无纯粹好坏的纸片人，人人有软肋与执念。
- **文笔**：短句金句，江湖豪情+庙堂悲凉+儿女情长揉在一起；独创"留白"技法——关键情节以他人转述呈现（徐骁屠城从未正面描写），重大情感爆发点用静默处理（"雪落无声，剑鞘轻颤"）。
- **结构**：庙堂与江湖双线并行，"棋局"隐喻贯穿；武戏即政戏，打斗即思辨。
- **文化熔铸**：武功招式承载文化——王仙芝拳意即盛唐气象，邓太阿剑气乃魏晋风骨，吴素剑舞藏《胡笳十八拍》悲声；借用历史人物原型（张巨鹿≈张居正、曹长卿≈曹植）但重新创造为"熟悉的陌生人"。
- **缺点（反面教材）**：中期战力膨胀、后期陆地神仙扎堆；部分支线铺垫过长、主线节奏忽快忽慢；结尾收束偏淡、配角结局留白过多。

### 0.3 《我在风花雪月里等你》— 都市情感 / 细腻心理
- **感情线（核心优势）**："大爱无声，却又震耳欲聋"——叶芷在男主断腿后推掉工作偷偷倒尿壶、记住 60 年约定、泰国机场五次回头、含泪拼好机票、"如果你的腿医不好，我就做你的翅膀"。感情不靠宣言，靠**具体行动与细节累积**。
- **心理刻画**：男主内心矛盾与挣扎刻画细致——"我恨她无情地抛弃我，又觉得自己亏欠她很多"，爱与不甘交织的复杂情感。
- **文笔**：细腻笔触、情感洞察、现实写照；第一人称贴合作者心境。
- **主题**：都市孤独、理想与现实挣扎、"没有赢家，在感情博弈中都满盘皆输"的复杂成人视角。
- **缺点（反面教材）**：后期拖沓扭曲、结尾潦草；男主"滥情的痴情"被读者诟病自私。

### 0.4 跨范例共性（高质量长篇网文的稳定特征）
1. **群像优先于孤胆**：配角弧光完整，可独立成线；主角通过与他者碰撞定义自身。
2. **留白与静默**：关键情感/转折不用直白宣告，用行动、意象、他人转述承载。
3. **意象/母题层层赋义**：核心意象跨章反复出现，每次赋予新义，形成重读价值。
4. **慢热耐心**：拒绝速成，日常与内省可以是章节主体；爽点随章节功能波动而非每章机械出现。
5. **文笔服务人物与心境**：金句与诗意不堆砌，化用典故不着痕迹；对话呈现人物身份与声音。
6. **文化/思想厚度**：武功/设定承载文化或哲思，而非纯粹力量升级。
7. **感情靠具体行动累积**：不靠宣言与心理总结，靠可触可感的细节与牺牲。

### 0.5 跨范例共性缺陷（AI 生成长篇需警惕的退化模式）
1. **机械报表化**：逐条复述蓝图、"他知道/意识到/这意味着"替读者下结论。
2. **支线冗杂/主线搁置**：多线铺开但收不回，主角几十章无实质推进。
3. **重复说教/意象泛滥**：同一哲理或意象反复出现无深化。
4. **战力/设定膨胀**：后期角色扎堆登顶，早期张力失效。
5. **结尾潦草**：长篇疲劳导致收束失重。
6. **群像工具化**：配角只为衬托主角而存在，无独立欲望与弧光。

## 1. 五大质量维度与可审计判据

> 每个维度给出：**定义**、**正例信号**（范例小说中可指认的具体表现）、**反例信号**（AI 生成常见退化）、**可审计判据**（审核时如何判定是否达标，避免"我觉得"式主观）。

### 维度 D1：世界观（Worldbuilding）

**定义**：世界规则自洽、文化/思想厚度、设定承载主题而非纯力量体系；规则可被读者内化预测，并在长篇中保持一致与深化。

**正例信号（范例）**：
- 《剑来》四座天下=儒释道四种文明秩序具象化；本命瓷隐喻命运枷锁；剑气长城探讨文明冲突。
- 《雪中》释道儒解释境界高低（金刚境喻释家/指玄境喻道家/天象境喻儒家），人物本领高低=精神境界高低。

**反例信号（AI 退化）**：
- 设定只为打怪升级服务，无文化或哲思承载。
- 规则随情节需要临时变更，读者无法内化预测。
- 世界观元素（势力/地理/历史）只在被用到时出现，无独立存在的质地。

**可审计判据**：
- W1 **规则可内化**：随机抽取世界观设定 3 条，问"若主角在 X 情境下做 Y，世界规则会如何反应"，答案可从已确立规则推导而非临时编造。判据：规则间无逻辑冲突，且可预测。
- W2 **文化/思想承载**：核心设定（修炼体系/势力结构/关键技术）至少有一个承载主题或哲思（如"程序=灵气本源"应承载秩序/逻辑/创造的哲思，而非只是力量来源）。判据：设定说明文含主题陈述，而非纯机制描述。
- W3 **跨章一致**：抽取 50 章跨度，世界观规则无矛盾（事实层由 continuity-reviewer 覆盖；世界观层判据是规则本身不漂移）。
- W4 **独立质地**：世界观元素在被用到之前已有铺垫或可感存在（如某势力在主角接触前已在他人对话/世界细节中出现）。

### 维度 D2：故事性（Storytelling）

**定义**：叙事结构精巧、伏脉千里、因果链可读、节奏随章节功能波动；多线交织但可收束；爽点随功能合理分布而非机械密集。

**正例信号（范例）**：
- 《剑来》"草蛇灰线，伏脉千里"——跨越数百章的伏笔闭环；书简湖问心局是"规则重构与道义坚守的深度思辨"而非武力比拼。
- 《雪中》庙堂与江湖双线并行，"棋局"隐喻贯穿，"武戏即政戏，打斗即思辨"；凉莽大战写出血肉与家国重量。

**反例信号（AI 退化）**：
- 逐条复述蓝图、把大纲压缩成当章任务清单。
- 主线几十章无实质推进，或反过来多个后续大纲节点压入一章。
- 爽点每章机械出现，或反过来长期无正向反馈。
- 因果链断裂：事件靠新线索/巧合推进，而非人物选择。

**可审计判据**：
- S1 **章节功能成立**：每章可识别承担的功能（开篇/过渡/冲突升级/高潮/余波/铺陈/相处/内省/阶段闭合），且正文实际完成该功能。判据：plot-reviewer 的 `plot`/`hookPayoff` 维度 + chapter.incomplete-blueprint 检查。
- S2 **伏笔闭环可追溯**：伏笔有埋设点与兑现点，兑现时有"原来如此"的回响而非突兀。判据：foreshadowing 记录含 setup_chapter + payoff_chapter + payoff 时引用 setup 证据。
- S3 **因果由人物驱动**：关键转折由人物选择/欲望/局限推动，而非外部新线索或巧合。判据：抽取章节转折点，追溯其因果链至人物选择而非"恰好出现"。
- S4 **节奏随功能波动**：铺陈/余波/相处章允许无爽点或低强度；行动/转折/闭合章需密集爽点。判据：reader-reviewer 的 payoff 曲线统计 + 章节功能匹配判断（已部分实现）。
- S5 **多线可收束**：支线数量在可控范围（如同时活跃 ≤ 5 条），且有明确收束计划。判据：plot-threads 记录含 status + 预期收束窗口。

### 维度 D3：群像塑造（Ensemble Cast）

**定义**：配角有独立欲望、弧光与声音；不是主角的工具人或回声板；重要配角可独立成线；群像间关系网络真实复杂。

**正例信号（范例）**：
- 《雪中》"随便拎一个配角出来，人物弧光完整到能单独开一本支线"——李淳罡/温华/轩辕敬城/徐骁/姜泥各有执念与软肋。
- 《剑来》齐静春殉道、崔瀺复杂、阿良潇洒、宁姚独立——"无绝对善恶，每位角色皆有自身的执念与道途"。

**反例信号（AI 退化）**：
- 配角主要服务于认可/衬托主角，无自身欲望。
- 配角对白声部混淆，多人一种腔调。
- 配角只在被需要时出场，无日常质地与独立存在。
- 关系网络扁平：只有"主角—盟友—敌人"三元结构。

**可审计判据**：
- E1 **配角独立欲望**：重要配角（出场 ≥ N 章）有明确自身欲望，且该欲望不总是与主角一致。判据：characters 记录含独立 desire/motivation 字段，且在章节中可观测到配角为自身欲望行动。
- E2 **声部可区分**：遮住角色名，仅看对白与行为，可区分是哪个角色。判据：盲测抽样——抽取 5 个角色的对白片段，能否以高于随机的准确率归属角色。
- E3 **弧光完整**：重要配角在长篇中有可指认的变化轨迹（信念/关系/处境）。判据：character memory 记录配角状态变化的时间序列。
- E4 **关系网络复杂**：角色关系非二元（盟友/敌人），含师徒/竞争/利用/暗恋/背叛等多维。判据：relations 记录含关系类型多样性，且关系随故事演变。
- E5 **配角日常质地**：配角在未被剧情需要时也有可感存在（提及/侧面出现/日常互动）。判据：章节正文中配角出现频率与剧情需要不成强相关。

### 维度 D4：感情线（Romance Line）

**定义**：感情靠具体行动与细节累积，不靠宣言与心理总结；感情发展有阶段性和不可逆性；感情线与主线/人物成长交织而非平行；感情有复杂度（不只是甜或虐）。

**正例信号（范例）**：
- 《风花雪月》叶芷"倒尿壶/60 年约定/泰国机场五次回头/含泪拼好机票"——大爱无声靠细节累积；"如果你的腿医不好，我就做你的翅膀"是行动承诺而非情话。
- 《剑来》陈平安与宁姚"你出剑，我断后"是精神契约，超越爱情的理念相互确认与补完。
- 《雪中》感情揉入江湖豪情与庙堂悲凉，"雪落无声，剑鞘轻颤"用静默承载重大情感爆发。

**反例信号（AI 退化）**：
- 感情靠角色心理总结（"他发现自己爱上了她"）而非行动。
- 感情发展无阶段性，从陌生到深爱无明确转折点。
- 感情线与主线平行，不互相影响人物成长。
- 感情只有甜或只有虐，无复杂成人视角。
- 女主工具化：只为满足主角情感需求而存在，无独立人格。

**可审计判据**：
- R1 **行动承载**：感情进展通过具体行动/细节/物件承载，而非心理总结或宣言。判据：抽取感情进展段落，行动/细节/物件占比高于心理总结。
- R2 **阶段性与不可逆性**：感情有可指认的阶段转变（陌生→相知→信赖→承诺等），且转变不可逆（不轻易回退）。判据：romance-progress 记录含阶段标记 + 转折章节，且后续章节不无理由回退。
- R3 **与主线交织**：感情线影响主角成长/选择，或反过来被主线影响。判据：感情转折点与主线转折点存在因果关系。
- R4 **女主独立人格**：女主有自身欲望、局限、成长，不只为满足主角情感需求存在。判据：女主 characters 记录含独立 desire/arc，且章节中可观测到女主为自身欲望行动。
- R5 **复杂度**：感情含矛盾、挣扎、取舍，而非纯甜或纯虐。判据：感情段落含"爱与不甘""责任与自由"等张力，而非单向情绪。

### 维度 D5：幽默（Humor）

**定义**：幽默贴合人物与情境而非硬抖包袱；幽默有层次（市井机锋/文人雅谑/荒诞反讽/情境喜剧）；幽默不破坏人物一致性；幽默作为调节而非每章强求。

**正例信号（范例）**：
- 《剑来》朱敛市井机锋、崔东山诡谲跳脱——对话各具声口，幽默是人物性格的自然流露。
- 《雪中》"小二上酒"的人间烟火；老黄"缺了门牙、总是呵呵憋笑"——幽默与人物形象深度绑定。
- 范例小说的幽默从不脱离人物独立存在，且常作为沉重叙事的调节。

**反例信号（AI 退化）**：
- 幽默是硬抖包袱或网络梗，与人物/时代不符。
- 每章强求幽默，破坏严肃段落张力。
- 幽默人物扁平化（只有"搞笑担当"功能）。
- 幽默与人物一致性冲突（严肃角色突然抖包袱）。

**可审计判据**：
- H1 **贴合人物**：幽默来自人物性格与处境，而非作者强插。判据：抽取幽默段落，删除后人物形象是否受损——若不受损则幽默是外挂的。
- H2 **时代/题材契合**：幽默用词/意象符合世界设定（古风不用网络梗，都市可用当代意象）。判据：幽默段落无时代错位的词汇或梗。
- H3 **调节功能**：幽默作为严肃叙事的调节，而非每章机械出现。判据：严肃/悲剧章节不强求幽默；幽默章节不破坏后续严肃张力。
- H4 **人物一致性**：幽默不破坏角色已建立的性格。判据：幽默段落可被该角色的性格说明解释。

## 2. 维度与现有 reviewer 的映射与缺口

> 对照 `src/novel-v2/prompts/chapter-review.ts` 的 `REVIEWER_DIMENSIONS`。

| 质量维度 | 现有 reviewer 覆盖 | 缺口 |
|---|---|---|
| D1 世界观 | continuity-reviewer（world/rule 术语）部分覆盖 | **无专门世界观评分维度**；规则可内化性/文化承载/独立质地未评估 |
| D2 故事性 | plot-reviewer (plot, hookPayoff) + reader-reviewer (readerRetention) | 伏笔闭环可追溯/多线可收束未作为评分维度；S2/S5 缺 |
| D3 群像 | character-reviewer (characterVoice, dialogue) 覆盖单角色 | **无群像维度**；配角独立欲望/弧光/关系网络复杂度未评估；E1/E3/E4/E5 缺 |
| D4 感情线 | character-reviewer 术语含 "romance" 但 **未进 REVIEWER_DIMENSIONS** | **感情线无评分维度**；R1-R5 全缺 |
| D5 幽默 | **完全无覆盖** | **幽默无评分维度**；H1-H4 全缺 |

**关键发现（Loop 1）**：用户要求的 5 大质量维度中，**3 个（世界观/群像/幽默）无专门评分维度，1 个（感情线）术语存在但未进评分**。这是审核闭环的根因层缺口——即使提示词写得好，审核层无法度量就无法驱动迭代。后续 loop 将评估：(a) 是否应新增评分维度 vs. 通过 skill 的 review 段补充 vs. 通过 craft-rule 沉淀；(b) 哪些维度适合硬门 vs. advisory。

## 3. 长篇耐久性补充判据（百万字支撑）

> 单章质量达标不等于长篇能力。以下判据用于评估流程是否支撑 50/200/500 章尺度，对应 framework audit 的"百万字支撑 3.5/10"。

| 尺度 | 风险 | 判据 |
|---|---|---|
| 50 章 | 角色声部混淆、伏笔漏兑现、重复意象/句式 | 盲测声部可区分；伏笔兑现率 ≥ 设定线；重复模式时间序列无上升 |
| 200 章 | 跨弧事实漂移、人物状态演变丢失、卷级高潮失重 | 跨 100 章事实问答准确率达预设线；character memory 状态时间序列完整；卷级高潮双评通过 |
| 500 章 | 长期疲劳、自我迭代安全（promote 不退化）、模式固化 | 跨题材 counterexample 回归集 + 冻结评估器；promote 回归含历史金标；弃读风险/追更动力时间序列 |

**注**：长篇耐久性证据需真实长篇生成，本审核目标不包含 50/200/500 章压力测试（属 novel-spirit-logic-fullbook 的产出），但会评估流程**是否具备**支撑长篇的结构（分层记忆/跨场景回归/疲劳检测）。

## 4. 标准版本与迭代

- **v1.0**（本版本）：基于范例研究推导的 5 维度 + 长篇耐久性补充判据；映射现有 reviewer 并识别缺口。
- **迭代触发**：当审核中发现本标准无法判定某类问题，或当范例研究扩展（新增范例小说）时，更新本标准并提升版本号。
- **与 skill/craft-rule 的关系**：本标准是**审核锚点**，不是 skill 本身；skill/craft-rule 是**生成与审核的实现**。本标准用于评估 skill/craft-rule 是否覆盖了应有维度。
