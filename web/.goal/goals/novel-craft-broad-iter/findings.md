### Prose 级对比（与雪中/剑来/庆余年实际片段）

#### 维度 1：去情绪化书写（差距 1.5 分，最突出）

**Draft 反例 1**（POV 越界式心理判断）：
> "方才在宫门外，这人说话带着西市的粗声粗气，进了东宫后，却像忽然换了一个人。殿门、灯火、宫人的目光，都没有让他的手乱上一分。"

- "却像忽然换了一个人" 是替视角人物判断他人心理状态——顾长安的"换人"是内心变化，韩景福无法直接观察。
- 庆余年范式（去情绪化）：五竹"黑布微扬，止步片刻才继续前行"——用可观察动作暗示心理，不直接判断。
- **改写方向**："方才在宫门外，这人说话带着西市的粗声粗气。入殿后他只是低头净手，打开木匣时指节未曾发颤。"

**Draft 反例 2**（作者式背景交代 + 格言式总结）：
> "韩景福在这里坐了多年，见过宫里一场风雪压弯过多少人的腰，也见过一句不经意的话改变多少人的脚步。"

- "见过...压弯过多少人的腰" 是格言式比喻，"一句不经意的话改变多少人的脚步" 是作者议论。
- 雪中范式：徐骁屠城细节从未正面描写，通过他人反应呈现。烽火强调"留白"与"画面感"。
- **改写方向**：通过当下具体动作或物件呈现经验感，如"他翻开灯簿，指腹在一处三年前的批注上停了停——那年冬天也下过这样一场雪"。

**Draft 反例 3**（作者式归纳）：
> "前殿的封禁、东宫的传令、缺失的一页旧档，此刻都落在同一个夜里。"

- 替读者归纳线索关联，剥夺读者判断空间。
- 剑来范式：陈平安通过"一砖一瓦"垒起道理，读者自行体会因果。
- **改写方向**：让线索通过场景并置自然显现，不点破关联。

**根因**：prose-prompts.ts 已有"禁止作者式心理结论句"硬约束（L94-106），列举了详细范式。但 LLM 仍生成——原因是约束过多导致漏读，且负面约束缺乏正面范本对比。

#### 维度 2：器物隐喻系统（差距 1.5 分）

**Draft 现状**：
- 韩景福：腰牌、朱签、牌票、拂尘——器物齐全但只承担功能，未参与抉择瞬间
- 顾长安：木匣、薄刃、药瓶、细绢——验尸工具，状态无变化
- 沈砚秋：旧档、纸封——线索载体，无隐喻层

**庆余年范式**：
- 范闲的菜刀：厨房切菜与战场杀人是同一把刀，折射暴力工具双重性
- 五竹的铁钎：未经修饰的原始力量
- 监察院黑骑盔甲反光：权力镜像效应
- 器物状态变化暗示人物处境转变

**差距**：Draft 中器物是道具，不是人物延伸。无一处器物参与抉择瞬间或状态变化暗示处境。

**根因**：imagery-aesthetics skill 已有"器物隐喻系统"规则（L100），但 skill 是"参考"层级，prose-prompts.ts 的硬约束未覆盖器物参与抉择。LLM 知道"器物应绑定"但不知道"如何在抉择瞬间使用器物"。

#### 维度 3：留白叙事（差距 1.5 分）

**Draft 反例**：
> "封禁之后仍有人在此查档，说明今夜之事已经不止是守门与传令能够解释的范围。"
> "今夜东宫牵涉的人太多，有些东西若不先留在手里，等该看的时候，未必还能看见。"

- 角色直接说出判断结论，替读者完成推理。
- 雪中范式：李淳罡的过去通过他人反应、环境变化呈现；温华断臂前铺垫极长，回收时爆发情感——关键信息用"不写"来写。
- **改写方向**：让韩景福的推断通过核对具体记录、发现具体异常、采取具体行动呈现，由读者自行得出结论。

**根因**：prose-prompts.ts 有"重大结果后允许人物暂不作决定...不要替人物总结'这意味着什么'"（L138），但约束偏抽象。LLM 在悬疑场景倾向于让角色"说出推理"以推进信息，需要更具体的"留白范式"正例。

#### 维度 4：句式节奏（差距 1.25 分）

**Draft 反例**（短句排比，quality-report 标 3 处）：
- 段 79-80、125-126、180-182 连续短句成段
- 如"他握着袖中的牌票，脚步未停。" + 下一段继续短句

**雪中范式**：
- 爆发段落用短句甚至单字段："剑出。人头落。"
- 抒情段落用绵长句
- 但日常叙事用长短句交错，不连续短句成段

**根因**：prose-prompts.ts 有"短句排比上限（硬约束）"（L113-115），quality.ts 有机械检测。但 LLM 在"连续报时辰/连续记录名字/连续下达命令/连续观察异常"场景仍触发。prompt 已预警这些触发场景，但 LLM 未内化。

#### 维度 5：群像声音区分（差距 1.0 分）

**Draft 反例**：
- 顾长安入宫前："这不是杂物，是吃饭的家伙。"（市井声音 ✓）
- 顾长安入宫后："人死了，都是一具身子。不过我会守规矩。"（声音趋同 ✗）
- 韩景福："宫里能长久留下来的，也只有这些话。"（理念总结 ✗）

**庆余年范式**：
- 费介用俚俗比喻解构权威
- 庄墨韩以考据腔调消解神圣
- 范闲以戏谑修辞解构崇高
- 每个人说话的句式、词汇、节奏都不同

**根因**：prose-prompts.ts 有"身份差异必须通过对白节奏、用词、句长、回避方式体现"（L155），但约束抽象。LLM 在"宫廷场合"会自动让所有角色采用"克制书面腔"。

#### 维度 6：意象功能化（差距 1.0 分）

**Draft 现状**：
- 雪/灯/安静/脚步 出现频繁但后半段同质化
- "雪压在檐角，风从廊柱间穿过，带得悬灯轻轻晃动" —— 美但只承担氛围
- quality-report 标"部分核心意象重复承担同一功能"

**雪中范式**：
- "雪"从初雪到暴雪到残雪，随徐凤年成长改变含义
- 意象每次出现必须呈现可辨识的新状态或新功能

**根因**：prose-prompts.ts 有"环境描写不得只承担氛围功能"（L140），但 LLM 在古风题材倾向于堆砌同类意象营造氛围。

### 根因分析（跨维度归纳）

**根因 1：Prompt 过载导致约束漏读**
- prose-prompts.ts 已 200+ 行，约束极多（"禁止/不得/违反即重写"出现 20+ 次）
- 短句排比 tic 禁令已存在但仍出现 3 处
- 作者式心理结论句禁令已存在但仍出现
- LLM 在长 prompt 下会"漏读"部分约束，优先级排序不明确

**根因 2：负面约束多，正面范本不足**
- prompt 大量"禁止X"但缺乏"应该怎么做"的具体范本
- classic-prose-texture skill 描述了烽火/猫腻技巧，但未引用实际片段
- LLM 知道"不要做什么"但缺乏"应该做什么"的质感锚点
- rewriteExample 由 reviewer 生成，可能延续同样的 prose 盲点

**根因 3：机械检测与生成脱节**
- quality.ts 短句排比检测是 post-hoc
- draft-stage pre-review 只 warn 不阻塞
- 生成时 LLM 不知道自己正在写短句排比
- POV 越界检测依赖角色名+动词模式，无法捕获"像换了一个人"式隐式越界

**根因 4：reviewer 无参考作品对比维度**
- 5 个 reviewer prompt 都基于规则检查
- 没有"与参考作品片段对比"维度
- reviewer 给出的 rewriteExample 是 LLM 自己生成的，可能延续同样的 prose 盲点
- 缺少"外部质感锚点"校准

**根因 5：skill 与 prompt 重复但未协同**
- prose-prompts.ts 和 skills.ts 有大量重复约束（短句排比、POV、作者式总结）
- prompt 是"硬约束"，skill 是"参考"，两者未形成协同
- LLM 在两者冲突时可能无所适从，或认为"已满足"而松懈

### 优化方向（覆盖多维度，不局限于单一文件）

| # | 方向 | 涉及文件 | 覆盖维度 | 优先级 |
|---|---|---|---|---|
| 1 | 在 prose-prompts.ts 增加"参考作品质感锚点"段落，直接引用雪中/剑来/庆余年 3-5 个实际片段标注技巧点 | prose-prompts.ts | 去情绪化/器物/留白/声音/意象 | 高 |
| 2 | 精简 prose-prompts.ts 重复负面约束，将部分约束移至 skill 层（让 prompt 聚焦"硬约束"，skill 聚焦"质感范本"）| prose-prompts.ts + skills.ts | 全维度 | 中 |
| 3 | 在 quality.ts 扩展检测：隐式 POV 越界（"像X一样""仿佛X"式他人心理判断）+ 场景后追加总结（段落以具体动作开始、以抽象结论结束）| quality.ts | 去情绪化/留白 | 高 |
| 4 | 在 draft-stage.ts 加入实时 POV 越界检测，对前一段输出做扫描，若检测到则在下一段 prompt 追加针对性约束 | draft-stage.ts | 去情绪化 | 中 |
| 5 | 在 review-stage.ts / prose-prompts.ts 的 reviewer prompt 中增加"与参考作品对比"维度，要求 reviewer 给出具体参考片段对比 | prose-prompts.ts + review-stage.ts | 全维度 | 高 |
| 6 | 在 skills.ts 的 classic-prose-texture 中加入"参考作品 prose 范本库"——3-5 个实际片段 + 技巧标注 | skills.ts | 去情绪化/器物/留白/声音/意象 | 高 |

### Loop 1 结论

Baseline 产物 prose 质感与参考作品（雪中/剑来/庆余年）在 6 个维度上存在 1.0-1.5 分差距，根因集中在 5 个跨维度问题（prompt 过载、正面范本不足、机械检测脱节、reviewer 无对比、skill 与 prompt 未协同）。优化方向覆盖 prose-prompts.ts / skills.ts / quality.ts / draft-stage.ts / review-stage.ts 多个文件，不局限于单一文件。

下一步：跑 bench-bootstrap 生成 fixture → bench-draft + bench-review 建立 fresh baseline → 实施 optimize 方向 #1/#3/#5/#6 → 重跑 bench 验证。
