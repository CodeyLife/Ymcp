# 10-state-after-planning.md
## 项目
标题：听雨剑
前提：末法时代，剑修沈青衫醒来时已失去百年记忆，只记得自己曾一剑斩断了某座山。他随身一柄无名锈剑，锈迹剥落处隐隐露出前人姓名。每斩一剑，锈落一分，他便记起一段被自己亲手抹去的旧事——而那些旧事，多是他对不起的人。他一路向西寻道，沿途遇见旧友旧敌，却无人认得他。随着记忆复苏，他逐渐接近那个被岁月掩埋的真相：他曾以一己之力封印天地灵脉，断绝了一个时代的修行路，而锈剑之中封存的，正是他遗失的剑心。
题材：仙侠、古典奇幻
受众：喜爱金庸、古龙、烽火戏诸侯风格的成人读者，偏好江湖气、人物群像、古典意境与复杂情感的长篇读者
主题：记忆、罪赎、寻道、失去与重拾、个人选择与时代因果
视角：有限第三人称 / 过去时 / 苍凉克制而偶有侠气，清冷底色中保留江湖温度与人物锋芒
语言风格：半文半白，追求中文意境美与古典美学。语言注重意象密度，以山河、器物、风雨、旧梦映照人物心境，通过动作、对白与留白承载情绪，避免直白宣告人物内心

## 架构
核心问题：当一个人为苍生断送一整个时代，他配不配再握剑。
核心冲突：沈青衫寻回记忆与面对记忆中累累罪孽之间的冲突。他想知道自己为何被世人遗忘、为何锈剑封存剑心，也必须承受那些被他改变命运之人的目光。
梗概：末法时代，剑修沈青衫醒于荒山古寺，百年记忆尽失，只留下一柄无名锈剑与一道无法解释的斩山痕迹。他向西而行，在寻找自身过去的路上，逐渐遇见那些曾与他并肩、敌对或被他伤害的人。锈剑每褪一层锈，便还他一段旧日因果，也让他距离真正的自己更近一步。昔日他为阻止天地灵脉失控，以一己之剑封闭一个时代的修行根基，成为许多人眼中的罪人。最终，他必须回答：若曾经的选择拯救了天下，却毁掉了无数人的未来，一个背负旧罪的人是否仍有资格执剑。
阶段：
- 2. 锈剑初醒：沈青衫从一场无名长眠中醒来，面对一个陌生而衰败的世道。他握着一柄锈迹斑斑的剑，只能从残缺的剑痕与旁人的避讳里感知过去的重量。在重新学习如何与这个时代相处时，他第一次发现，自己遗忘的并非荣耀，而可能是一生无法偿还的亏欠。；转折：沈青衫在一次危局中第一次拔剑，锈剑褪下一层锈迹，显露出一段被封存的旧名，也让世人确认他与百年前那场断绝灵脉之变有关。
- 3. 西行寻道：沈青衫踏上向西的道路，沿途穿过末法大地上的城镇、宗门与遗迹。他遇见不愿原谅他的旧人，也遇见从未见过他却继承着他留下伤痕的人。每一次同行与别离，都让他重新审视自己曾经坚信的选择，也让锈剑中的剑心逐渐回应他的呼唤。；转折：沈青衫找到当年封印天地灵脉的核心遗迹，得知自己并非简单的救世者或罪人，而是在多个选择都走向毁灭时选择了承担代价的人。
- 4. 旧债新偿：真相逐渐浮现后，沈青衫不再只是追寻失去的记忆，而开始面对那些因他的决定失去道路、亲人与未来的人。他必须在补偿、赎罪与守护之间寻找新的答案，也必须接受有些伤痕无法被一句道歉抹平。；转折：沈青衫重新面对当年最重要的敌手与旧友，确认封印并非结束，而是留下了一场延续百年的因果。他选择承担打开旧局的风险，而不是继续躲在遗忘之中。
- 5. 剑心归位：沈青衫走到旧时代与新时代交汇之处，终于取回完整记忆，也看清自己真正失去的并非力量，而是承认自己曾经做过选择的勇气。他不再追求洗清罪名，而是在众人的目光中决定未来该由谁来承担。；转折：沈青衫取回锈剑中封存的剑心，以新的剑意面对天地规则，让剑不再代表过去的牺牲，而成为守护后来者的道路。
