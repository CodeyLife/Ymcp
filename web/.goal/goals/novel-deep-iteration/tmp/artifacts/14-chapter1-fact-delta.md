# 事实差异

沈青衫在荒山山神庙醒来，处于失忆状态，携带一柄锈剑并感知到其中的微弱剑意。他决定离开山神庙寻找过去，在途中与盲眼琴师阿落相遇，琴声再次触发他关于斩山剑光的模糊记忆。

- entities.character.state.location：荒山山神庙
  - 证据：沈青衫睁开眼时，发现自己躺在一尊残破神像旁的旧草席上。
  - 置信度：100%
- entities.character.state.memory：失去大部分过去记忆，只记得一剑斩山的画面
  - 证据：他什么都想不起来；从醒来到现在，他脑中唯一清晰的画面，便是一剑斩山。
  - 置信度：100%
- entities.character.state.inventory：锈剑
  - 证据：在神像旁边，靠着一柄剑。那是一柄很旧的剑。
  - 置信度：100%
- entities.character.abilities：能够感知锈剑中的微弱剑意
  - 证据：一缕极微弱的剑意从锈迹深处传来，没有杀意，也没有锋锐，只像一个沉睡太久的人，在黑暗中回应了一声。
  - 置信度：95%
- entities.character.state.relationshipNotes：唯一清晰记忆与一剑斩山有关
  - 证据：他看见一片高山，云层之上有剑光落下，山峰断裂。
  - 置信度：100%
- entities.character.abilities：拥有残存但无法完全触碰的力量
  - 证据：体内确实有一道残存的气息。微弱。断裂。
  - 置信度：100%
- entities.character.state.objective：寻找失去的过去与锈剑真相
  - 证据：这座山神庙没有留下他的过去。那便离开。
  - 置信度：100%
- entities.name：沈青衫
  - 证据：我叫阿落。沈青衫点头。沈青衫。
  - 置信度：100%
- entities.character.state.relationshipNotes：阿落琴曲与沈青衫失落记忆存在关联
  - 证据：听见它时，他眼前再次浮现出那座山。雨夜。剑光。
  - 置信度：100%
- entities.character.state.knowledge：无法确认斩山事件的原因与后果
  - 证据：他不知道自己为何挥剑，不知道那座山为何断裂，也不知道那一剑之后发生了什么。
  - 置信度：100%
