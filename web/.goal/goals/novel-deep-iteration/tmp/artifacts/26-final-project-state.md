# 26-final-project-state.md
## 项目
标题：听雨剑
前提：末法时代，剑修沈青衫醒来时已失去百年记忆，只记得自己曾一剑斩断了某座山。他随身一柄无名锈剑，锈迹剥落处隐隐露出前人姓名。每斩一剑，锈落一分，他便记起一段被自己亲手抹去的旧事，而那些旧事，多是他对不起的人。他一路向西寻道，沿途遇见旧友旧敌，却无人认得他。随着记忆逐渐复苏，他发现自己曾以一己之力封印天地灵脉，断绝了一个时代的修行路，而锈剑之中封存的，正是他失去的剑心。
题材：仙侠、古典奇幻、长篇江湖群像
受众：喜爱金庸、古龙、烽火戏诸侯风格的成人读者，偏爱古典意境、人物群像与苍凉江湖叙事的读者
主题：记忆、罪赎、寻道、人在失去过去之后如何重新面对自己曾经的选择、一个时代终结后的众生归途
视角：有限第三人称 / 过去时 / 苍凉克制，偶有侠气与温暖
语言风格：半文半白，追求中文意境美与古典美学；语言凝练含蓄，重视山水意象、器物象征与情绪留白

## 架构
核心问题：当一个人为苍生断送一整个时代，他配不配再握剑。
核心冲突：沈青衫寻回记忆与记忆中尽是罪孽之间的冲突。他必须面对曾经那个拯救众生却也亲手截断修行时代的自己，并在承认旧罪与重新选择未来之间寻找真正的剑心。
梗概：末法时代，沈青衫从一场沉睡中醒来，遗失百年记忆，只携一柄无名锈剑行走世间。他记得自己曾一剑斩断一座山，却不知道那一剑为何而出，也不知道世人为何对他讳莫如深。随着锈剑上的锈迹一点点剥落，沉睡其中的旧事逐渐归来：他曾是那个时代最锋利的剑修，也曾在天地将倾之际，以自身之剑封死天下灵脉，让一个璀璨修行时代走向终结。有人称他救世，有人称他罪人，而那些被他留下的人，都在漫长岁月里以各自方式承受那一剑后的余波。
阶段：
- 2. 锈剑初醒：沈青衫在陌生的世间醒来，像一柄被遗忘在荒野里的旧剑。他背负着无人知晓的空白，也背负着世人眼中的传闻。一路向前，他从零碎的山河、人情与旧物中感受到那个曾经属于自己的时代正在远去，而手中的锈剑却比任何人都记得过去。；转折：沈青衫第一次完整忆起自己曾亲手斩断一座山脉灵脉，并发现那一剑并非失误，而是自己主动做出的选择。
- 3. 西行寻道：沈青衫踏上向西之路，在荒凉的末法大地上寻找剑与人的答案。旧友与旧敌相继出现，他们带来的不是欢迎，而是一笔笔无法逃避的旧账。那些曾被他改变命运的人，让他逐渐明白，自己失去的不只是记忆，还有面对过去的勇气。；转折：沈青衫抵达西方旧地，发现锈剑中封存的并非单纯力量，而是他主动舍弃的剑心，以及当年封印天地灵脉背后的真正代价。
- 4. 旧债新偿：当过去彻底揭开，沈青衫不再能够以失忆者的身份逃避。他面对曾经保护过的人、伤害过的人与因他而改变一生的人，在废墟般的新世界里重新寻找人与剑之间的关系。每一次出剑，都不再只是胜负，而是对旧日选择的回应。；转折：沈青衫得知当年封印灵脉并非结束，而是将毁灭延后的第一步。他必须决定是否再次承担那个无人愿意承担的代价。
- 5. 剑心归位：沈青衫终于走到自己曾经留下的终点。在天地与众生的选择面前，他不再追问过去的自己是否正确，而是在经历过失去、误解与悔恨之后，重新决定何为一剑。那柄锈剑最终褪去旧痕，却留下一个不属于过去的答案。；转折：沈青衫重新握剑，却不再成为旧时代的剑修，而成为一个愿意与新时代众生同行的人。

## 剧情线 (4)
- [growth] 沈青衫从避罪到承担：沈青衫最初试图以失忆者身份逃离过去，将百年前的自己视作陌生之人。随着旧友、旧敌和受影响之人的出现，他逐渐承认过去的选择属于自己，并重新寻找愿意承担代价的剑心。
  状态：active；下一步：通过面对顾长安、锈剑中的旧我以及受封脉影响的人，沈青衫放下证明过去正确的执念，开始为今日之人重新出剑。
- [antagonist] 谢道临追剿沈青衫：谢道临因断天灵脉封印变化追寻沈青衫，认为这个曾改变天下命运的人必须回答新的天下之问。两人的冲突不仅关乎个人恩怨，也关乎末法时代是否还能寻找新的道路。
  状态：active；下一步：谢道临沿沈青衫西行轨迹追查，在旧地遗迹和封印线索中逼近沈青衫，最终要求他面对过去与未来的选择。
- [main] 沈青衫西行寻道与记忆回收：沈青衫携锈剑踏上西行古道，在末法时代的荒凉山河中寻找失落的过去。随着锈剑锈迹剥落，他逐渐面对百年前封脉之举留下的旧事，也重新认识那个被自己舍弃的剑心。
  状态：active；下一步：沿西行古道追寻旧时代遗迹，通过顾长安留下的线索、锈剑中的残缺记忆和旧地见闻，逐步确认断天灵脉封印的真正代价。
- [subplot] 阿落寻仇不知仇人在身边：阿落带着父亲之死留下的仇恨追寻旧日凶手，在同行过程中逐渐发现沈青衫与那场旧日杀局有关。她必须在仇恨、真相与眼前这个失去记忆的人之间做出选择。
  状态：active；下一步：在旅途中通过盲琴、旧物或旁人记忆获得父亲死亡线索，逐渐察觉沈青衫与旧日杀声之间的联系。

## 伏笔 (5)
- 锈剑名字里的旧罪：沈青衫醒来后，锈剑锈迹剥落处逐渐露出陌生姓名。每当一个名字完整显现，剑身会回应一段零碎画面，其中包含死去之人、旧地与他曾经挥剑留下的痕迹。旁人听见这些名字时，往往避而不谈，只留下含混评价。
