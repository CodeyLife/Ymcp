# 规划剧情线

沈青衫西行寻道、阿落追寻旧仇、谢道临追查沈青衫以及沈青衫重新面对过去责任的故事线正在展开，各线围绕旧日记忆、因果与选择逐步推进。

## 1. 沈青衫西行寻道与记忆回收

该故事线承担整体推进作用，围绕沈青衫西行、寻找记忆与面对过去展开。

- 操作：新增
- 类型：plotThreads

### 内容
**类型**：main
**标题**：沈青衫西行寻道与记忆回收
**摘要**：沈青衫携无名锈剑踏上西行之路，在山河旧迹与故人遗痕中寻找失落的百年记忆。每一次剑锋与旧事相逢，都让他重新面对曾经的选择，并逐渐接近自己封印天地灵脉的往事。
**状态**：active
**优先级**：90
**下一步**：沈青衫将在西行途中追寻锈剑剥落后的线索，通过一次与旧地、旧人的相遇，回收第一段关键记忆，同时发现过去的自己并非单纯的救世者或罪人。

## 2. 阿落寻仇不知仇人在身边

该支线围绕阿落的追查与仇恨认知变化展开，并与西行过程产生交集。

- 操作：新增
- 类型：plotThreads

### 内容
**类型**：subplot
**标题**：阿落寻仇不知仇人在身边
**摘要**：阿落背负旧日血仇踏上追索之路，寻找那个改变自己命运的仇人。她一路追查线索，却未察觉真正与那段仇怨相连的人就在身边，仇恨与真相将在相处和冲突中逐渐发生偏移。
**状态**：active
**优先级**：70
**下一步**：阿落将在西行途中与沈青衫同行或交错相遇，从细节中发现更多关于旧案的线索，同时因亲近之人的行为产生怀疑，逐步动摇原本坚定的复仇目标。

## 3. 谢道临追剿沈青衫

该故事线承担追查与对抗作用，推动沈青衫面对外部压力。

- 操作：新增
- 类型：plotThreads

### 内容
**类型**：antagonist
**标题**：谢道临追剿沈青衫
**摘要**：谢道临奉行自己的判断追查沈青衫，将其视为与末法时代灾变有关的人物。追剿过程中，他不断接近沈青衫留下的痕迹，也逐渐触碰到被隐藏的时代真相。
**状态**：active
**优先级**：70
**下一步**：谢道临将制造一次迫使沈青衫无法继续隐藏身份的追逐局面，使沈青衫第一次正面面对过去留下的因果，同时让谢道临发现追剿目标可能并非自己认知中的罪人。

## 4. 沈青衫从避罪到承担

该成长线记录沈青衫面对过去责任的变化，与主线发展相互关联。

- 操作：新增
- 类型：plotThreads

### 内容
**类型**：growth
**标题**：沈青衫从避罪到承担
**摘要**：失去记忆的沈青衫最初试图避开过去的罪责，只想找到失去的剑心与答案。随着记忆逐渐回归，他不得不承认曾经的选择带来的时代影响，并在逃避与承担之间重新选择自己的道路。
**状态**：active
**优先级**：85
**下一步**：沈青衫将在一次必须做出选择的事件中放弃隐藏过去的身份，承担一次由旧日决定引发的后果，从而完成从逃避者到承受者的第一次转变。
